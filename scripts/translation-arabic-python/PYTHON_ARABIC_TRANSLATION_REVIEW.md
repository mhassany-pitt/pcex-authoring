# PCEX Python Curriculum: Arabic Translation Review

## 1. Reviewer Instructions

### How to Access and Review Sources in the PCEX Tool
1. **Direct PCEX Editor Link**:
   - Click on any **Source ID** in the table below to open it directly in the PCEX Editor (`https://adapt2.sis.pitt.edu/pcex-authoring/#/editor/<source_id>`).
   - The editor will display all Arabic texts: Title, Description, Code literals/prompts, Comments, and Distractors.
2. **Comparison with Original English**:
   - In the top right corner of the PCEX editor, click **"View Untranslated / Original"**.
   - All original English texts (`untr_name`, `untr_description`, `untr_code`, `untr_comments`, and `untr_*` distractors) are preserved in the same file.
3. **Approval & Tagging**:
   - All newly translated items currently carry the `validation-pending;color=orange` tag.
   - Once reviewed and approved, simply remove the `validation-pending;color=orange` tag from the source's tag list.
